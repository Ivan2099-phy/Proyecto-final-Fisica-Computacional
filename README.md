 Proyecto Final: Física Computacional

## Overview
This project implements the **Hartree-Fock method** to approximate solutions of the **Schrödinger equation** for molecular systems. It provides a framework for quantum chemical calculations using Python, featuring a Self-Consistent Field (SCF) method, basis set management, and integral calculations for electrons.

## Features
- **Hartree-Fock Method**: Approximates the wavefunction and energy of a quantum many-body system.
- **Self-Consistent Field (SCF) Method**: Iteratively solves the Schrödinger equation for molecular systems.
- **Basis Set Management**: Efficiently handles molecular orbital representations.
- **Integral Calculations**: Computes electron-electron interactions and other integrals necessary for quantum chemistry.
- **Visualization**: Includes Jupyter notebooks for data visualization and analysis of results.
